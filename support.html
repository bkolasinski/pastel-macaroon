Open a support request

Describe a reproducible theme problem and this form will prepare a ticket in the public Pastel Macaroon support queue.

New requests receive an initial response within two business days. Critical defects that block storefront browsing, purchase or checkout handoff are triaged immediately when received.

Do not include private or sensitive information. Submitted tickets are public. Never provide passwords, customer or payment data, API credentials, Theme Access passwords, private app tokens or unredacted admin screenshots. GitHub requires an account when you submit the prepared ticket.
Use a name or GitHub username that may safely appear in a public ticket. Do not enter a private email address.
