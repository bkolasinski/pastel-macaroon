Installed-theme guide · version 1.0.0

Make Pastel Macaroon your own

This guide describes the settings, sections, blocks, templates and storefront behavior provided by Pastel Macaroon after the theme has been added to your store.

Scope: use this guide to configure Pastel Macaroon itself. Store setup and administration that do not change this theme are intentionally outside the guide.

01 · First configuration

Start with the installed theme

Open Pastel Macaroon in the theme editor and work through the following order. Save after each group of changes and use the desktop and mobile previews before publishing your customized copy.

  1. Set the logo, brand fallback text, typeface, content width and color palette in Theme settings.
  2. Select the main navigation and customer-account menu in Header.
  3. Replace the default Home copy and connect the Home sections to your own images, products and collections.
  4. Review the Product template blocks, especially variants, purchase options, quantity, buy buttons and product recommendations.
  5. Configure the Footer blocks and social links, then review Collection, Search, Cart, Contact and Password templates.
Your store content is not bundled with the theme. Pastel Macaroon starts with portable text and empty resource selectors. Products, collections, menus, blogs, pages and uploaded media must be selected from your store. Where possible, the theme displays catalog-based fallbacks or a neutral placeholder until you make a selection.

How settings are organized

  • Theme settings affect the whole storefront.
  • Section settings affect one instance of a section on one template.
  • Blocks can be added, removed and reordered inside supported sections.
  • Blank button labels hide their buttons. Several button links fall back to the all-products page when a visible label has no link.

03 · Storewide sections

Header, announcement bar and footer

Announcement bar

The announcement bar spans the viewport. Leaving Text blank hides it. Add an optional Link, choose whether it should Open link in a new window, set Alignment, and choose independent Background color and Text color. New-window links include an accessible notice.

Header

Select the Main menu and Customer account menu. The Header renders the logo or text fallback, desktop and mobile navigation up to three levels deep, search with predictive product/article/page results, a cart count and the optional color-mode toggle. The account control appears only when customer accounts are enabled for the store.

Featured content in a menu

Add up to six Menu promotion blocks inside Header to feature an image or a link alongside a main-menu item. On desktop, the feature appears beside the submenu links inside the page width. On mobile, it appears below those links in the existing navigation panel.

Header blockControls and behavior
Menu promotionMenu item link identifies the top-level menu item by its destination, not its name. Choose an Image, a Heading, or both. The optional Link controls where the featured card leads; when blank, it uses the menu item's destination.

For example, if a top-level menu item opens a collection, select that same collection in Menu item link, then choose the image and heading for the feature. Renaming the menu item does not break the match. A menu item without child links can also have a promotion; its compact, single-column dropdown keeps a View all link above the featured card.

Menu item link must point to a page in your own store, without a # anchor. The first matching block is used for the first menu item with that destination. Use distinct destinations when you need different features. Blocks with neither an image nor a heading do not add a feature; with an image but no heading, the menu item's name becomes the card heading. If no menu item matches, the ordinary navigation stays unchanged. The menu and its links remain usable without JavaScript.

Footer

The Footer accepts up to five reorderable blocks. Its section settings are Description, Show social media links, Show Follow on Shop, and URL fields for Facebook URL, Instagram URL, YouTube URL, TikTok URL, Pinterest URL and X URL.

Footer blockControls and behavior
BrandOne block maximum. Displays Brand text or the store name plus the Footer Description.
MenuHeading, Footer menu and Show policy links. If Heading is blank, the selected menu title is used.
NewsletterOne block maximum. Configure Heading, Text and Button label.
Social linksOne block maximum. Configure its Heading. It displays the store email, completed social URL fields and the Follow on Shop control when those outputs are available.
TextReusable block with a Heading and Text.
App blockDisplays a compatible installed app extension inside the Footer.

Country/region and language selectors appear automatically below the Footer blocks only when the current storefront offers more than one country or language. Empty social URL fields do not create empty links.

04 · Home template

Build the Home page

The installed Home template starts with Home page hero, Featured collections, Featured products and Brand story. You can reorder, remove or duplicate these sections and add any of the reusable sections described later.

SectionControls and exact fallback behavior
Home page heroEyebrow, Heading, Description, Button label, Button link, Hero image and Fallback product image. Image priority is Hero image, selected product image, first catalog product image, then placeholder. A visible button without a link opens all products.
Featured collectionsSection Heading and Description, plus up to three Collection blocks. Each block has Heading, Collection, Image and Fallback product image. Card image priority is custom image, collection image, fallback product image, matching catalog-position image, then placeholder.
Featured productsEyebrow, Heading, Description, an ordered list of up to eight Products, Button label and Button link. With no selected products, the first eight catalog products are used; an empty catalog shows four placeholders. A visible button without a link opens all products.
Brand storyEyebrow, Heading, Description, Primary image product, Secondary image product, Button label and Button link. Blank product selectors use the first two catalog products; missing images become placeholders. A visible button without a link opens all products.

Product cards used across the Home page, catalog and recommendations automatically show Sold out and Sale badges. The case-insensitive product tags new and sparkly add the matching editorial badge.

05 · Reusable content

Addable sections and theme blocks

Add these sections where the theme editor makes them available. Every instance stores its own content and resource selections.

Slideshow

Supports up to six Slide blocks. Section controls: Accessibility label, Height (Small, Medium or Large), Auto-rotate slides and Change slides every 3–9 seconds.

Each slide has Image, Mobile image, Eyebrow, Heading, Text, Button label, Button link, Open link in a new window, Content position and Overlay opacity from 0–80%. Manual controls remain available with or without autoplay; reduced-motion preferences stop automatic movement.

Featured collection

Configure Collection, Eyebrow, optional Heading and Description, Products to show (2–12), Columns on desktop (2–4), Columns on mobile (1–2), Show View all link and View all label. A missing collection displays four neutral product-card placeholders.

Featured product

Select a Product and choose Show vendor, Show description and Show accelerated checkout buttons. The section includes product media, variant and selling-plan selectors, price and unit price, quantity, gift card recipient fields where applicable, Add to cart and an optional accelerated checkout button.

It also accepts Custom Liquid with a Liquid code setting and compatible App blocks.

Collection list

Controls: Eyebrow, Heading, Description, Collections per page (3–24), Columns on desktop (2–4), Grid spacing (0–50 px) and Image fit (Contain or Cover).

Add up to ten Collection blocks, each with a Collection selector, for a manual order. With no blocks, the dedicated Collection list template paginates all collections; other templates show up to the configured limit.

Image with text

Configure Image, Image caption, Image position, Image ratio (Wide 16:9, Landscape 4:3, Classic 3:2, Square 1:1 or Portrait 4:5), Image fit, Eyebrow, Heading, Text, Button label, Button link and Open link in a new window. A visible button without a link opens all products.

Rich text

Choose Content width and Alignment; add Eyebrow, Heading and Text. Two optional actions have independent Primary button label, Primary button link, Open primary link in a new window, Secondary button label, Secondary button link and Open secondary link in a new window. A label makes its action visible; a missing primary link opens all products and a missing secondary link opens the collection list.

Newsletter

Configure Eyebrow, Heading, Text, Button label, optional Link label, Link, Open link in a new window and Disclaimer. The form reports success and errors within its own section instance.

Blog posts

Select a Blog; configure Eyebrow, Heading, Description, Posts to show (2–4), Image ratio, Image fit, and toggles for Show date, Show author, Show comment count and Show View all link. Customize the View all label.

Video

Select either a Shopify-hosted video or an external YouTube or Vimeo URL; a hosted video takes priority when both are filled. Configure Accessibility label, Eyebrow, Heading, Text, Width, Autoplay and Loop video. Autoplay is muted; player controls remain available. With no source, the section shows a video placeholder.

Custom Liquid

The Liquid code field renders exactly the Liquid you provide. A blank field emits no section wrapper. Use this only for code you can maintain and retest after theme updates.

Custom section and nested theme blocks

Select an optional Background image, then build the content with nested theme blocks. The image uses its saved focal point.

  • Group: Layout direction, conditional Alignment for vertical groups, and Padding from 0–200 px. A Group can contain more theme blocks.
  • Text: Text, Text style (Title, Subtitle or Normal), and Alignment.

06 · Product detail

Configure the Product template

The section-level controls are Recommendations heading and Products to show (2–8). Related products load below the main product; the area stays hidden when no results are available.

The gallery supports images, hosted video, YouTube/Vimeo media and 3D models. Multiple media items receive thumbnails; images open in a keyboard-accessible dialog; eligible 3D media can show View in your space.

Reorderable blockBehavior and settings
Vendor and product typeIndependent Show vendor and Show product type toggles.
HeadingDisplays the product title.
SKUUpdates when the selected variant changes and hides when the SKU is blank.
PriceCurrent and compare-at prices plus the relevant tax and shipping-policy notice.
Unit priceDisplays only when the selected variant has unit-price measurement data.
DescriptionRenders the product description as formatted content.
Variant pickerOption selectors with Show variant swatches. Values without swatch data remain readable text.
Quantity selectorQuantity controls that follow the selected variant's minimum, increment and optional maximum rules.
Purchase optionsOne-time and available selling-plan choices. Hidden when the product has no selling plans.
Buy buttonsAdd to cart, gift card recipient fields when applicable, and optional accelerated checkout controlled by Show accelerated checkout buttons.
Pickup availabilityVariant-specific pickup status and locations. Updates after a variant change.
InstallmentsDisplays payment terms when the current product and storefront context provide them.
Complementary productsHeading and Products to show (1–10). The block stays empty when no complementary results exist.

Keep the Heading, Variant picker, Quantity and Buy buttons in a practical order. Removing a block removes that information or control from the template; it does not change the underlying product.

On Product and Featured product, Add to cart uses a light surface with a colored border. The unbranded Buy it now button uses a filled gradient from your Primary color and Secondary color, with matching rounded corners and hover feedback. Both follow your theme palette; Buy it now also adapts its text color in dark mode. When a branded wallet button such as Shop Pay or Apple Pay appears instead, it keeps that provider's colors and branding.

07 · Shopping flow

Catalog, search and cart templates

Product card images

Turn on Theme settings → Product cards → Enable image browsing to add previous and next image controls to cards with multiple images. This applies to Collection, Featured collection, Featured products, Recommended products and product results on the Search page. It does not change the compact suggestions inside the Header search or Complementary products.

Cards start with the product's featured image or media preview and offer up to three additional product images. Customers can use the arrow buttons, operate them with the keyboard, or swipe horizontally over the image on a touch screen. Clicking the image or product name still opens the product page. Images do not advance automatically, and extra images load only when requested. Videos and 3D models remain on the product page, not in this image browser.

Turn the setting off to keep one static image per card. Products with one image or no image never display image controls; without JavaScript, the first image and product link remain usable.

Short descriptions on product cards

Enable Theme settings → Product cards → Show short description to display a short introduction below the product name and above its price. It applies to the same full product cards listed above, not the compact Header search suggestions or Complementary products. The setting is off by default to keep cards compact.

The card uses the first 20 words of the product's description, adding an ellipsis when there is more text. Edit the beginning of each product's description to make this introduction useful; there is no separate card-description field. Formatting and embedded images are removed, and links become plain text. If the description has no text, no excerpt or empty gap is added. The excerpt works without JavaScript, and the full description on the product page is unchanged.

Collection

Controls: Eyebrow, Show filters, Show sorting and Products per page (6–36 in steps of 3). The page uses the collection title, description and image, paginates product cards and preserves active filters while sorting. If native filter values are unavailable, the theme can offer product type, vendor and tag filters from the catalog.

Search page

Controls: Eyebrow, Heading, Description, Show filters, Show sorting, Results per page (6–36 in steps of 3) and Columns on desktop (3 or 4). Results can include products, articles and pages. Filtering appears after a search only when usable values exist; active filters and the original query are retained through sorting and pagination.

Cart

Choose Theme settings → Cart → Cart behavior to switch between Drawer and Cart page. The drawer opens from the Header cart icon and after adding an item from Product, Featured product or Complementary products. Customers can close it to continue browsing, choose View cart for the full page, or continue to checkout. It is a storewide setting, not a section you need to add to a template.

Both cart views show the selected variants, purchase plans, customer-supplied item details and uploaded-file links, unit prices, applicable item and cart discounts, totals and tax/duty/shipping notices. Customers can change quantities, remove items and add an order note. Changes update in place, and notes in the drawer save automatically. Checkout and any available accelerated checkout buttons remain available.

Full cart page controls: Description, Upsell heading and Cart upsell product. If no upsell product is selected, the first catalog product is used. The upsell renders only for an available variant that does not require a selling plan. These controls customize the full page, not the drawer.

The full cart page stays available in either mode and never opens a second cart panel over itself. If JavaScript is unavailable, cart links and purchase forms use the full cart page, where the ordinary update and checkout forms remain usable.

08 · Pages and editorial content

Content and utility templates

Blog and articles

The Blog template displays six article cards per page with image, publication date, author, excerpt and comment count when comments are enabled. Its editable fields are Eyebrow and Description. The Article template renders the featured image and article content; when comments are enabled it paginates comments ten per page and displays the comment form with moderated or immediate-submission feedback.

Standard page

Displays the page title and formatted page content in the Pastel Macaroon page layout. Add reusable sections around it when you need richer storytelling.

Contact page

Editable fields are Eyebrow, Description, Response time, Show store address and Show phone field. The details card displays the store name, store email and—when enabled and available—the physical address. It never displays the store website address.

The form contains Name, required Email address, optional Phone and required Message. Email address is the customer's reply address; there is no recipient field, and submission uses the store's configured contact recipient.

Password page

Configure Eyebrow, Heading, Text and Show email signup. When signup is shown, configure its Heading, Text and Button label. A store-level password message takes priority over the section Text. The page includes the logo/store-name treatment, newsletter feedback and password-entry form.

Not found page

Provides a styled recovery page with a Search form and a button leading to all products.

Gift-card page

Uses the global palette and logo settings. It displays balance, active/expired/disabled state, expiry date, recipient, message, scheduled send date, redemption code and QR code. Add to Apple Wallet appears only when the gift card supplies an eligible pass URL.

10 · Maintenance

Update Pastel Macaroon safely

Documentation status: this guide is reviewed whenever Pastel Macaroon changes and currently applies to version 1.0.0. After adding a newer version, use the guide and release notes that carry that version number.

  1. Keep a duplicate of the currently published theme as a rollback copy.
  2. Read the Pastel Macaroon release notes, then add the offered update as a draft theme.
  3. Review the updated draft. Confirm global settings, section order, block order, selected resources, app blocks and any source-code edits.
  4. Retest Header navigation and search, Product variants and purchase controls, Cart editing, Contact, Footer and any templates or custom code your store relies on.
  5. Publish only the verified draft and retain the previous working copy until the new version has been observed in production.

Pastel Macaroon uses MAJOR.MINOR.PATCH versions. Patch and minor releases aim to preserve editor configuration. A major release includes explicit migration notes. Source edits and Custom Liquid remain your responsibility and may need manual review or reapplication.

11 · Problem solving

Troubleshoot before changing content

  1. Confirm that the version badge in this guide matches the Pastel Macaroon version shown in Theme settings.
  2. Open the affected page in the theme editor and confirm that you are changing the active template and the intended section instance.
  3. Check whether the relevant image, product, collection, menu, blog or page selector is blank. Review the documented fallback or conditional behavior before replacing content.
  4. Preview the same page at desktop and mobile widths. If the problem appears in only one browser, retest in a current private window with browser extensions disabled.
  5. If the page contains custom Liquid, source edits or app blocks, reproduce the problem in a clean, unmodified copy of the same Pastel Macaroon version.

If these checks do not resolve the problem, review the FAQ below and then include the results when opening a support request.

12 · FAQ

Frequently asked questions

The logo is replaced by text
Choose a Logo in Theme settings. When no image is selected, the Header uses Brand text and then the store name. The Password page uses the store name, while the gift card page uses its built-in gift card image when no logo exists.
A home page section shows unexpected products or placeholders
Review the exact fallback order in the Home page section above. Home page hero, Featured collections, Featured products and Brand story intentionally use catalog products when their selectors are blank. Select explicit resources when the order matters.
The account icon is missing
The Header renders its account control only when customer accounts are enabled. The Customer account menu setting controls the menu passed to that account control.
Filters or sorting are missing
Confirm Show filters or Show sorting is enabled on the active Collection or Search page template. Filters render only when usable filter, product type, vendor or tag values exist; the Search page filter panel appears only after a search has been performed.
Swatches appear as text
Enable Show variant swatches in the Product Variant picker and confirm the option values contain color or image swatch data. Text is the intentional accessible fallback.
Product cards do not show image arrows
Enable image browsing in Theme settings → Product cards and check that the product has another distinct product image. The card shows up to four images, starting with its featured image or media preview. Cards with only one image, missing images or JavaScript disabled intentionally keep the static presentation.
A product card description is missing or needs different wording
Check Show short description in Theme settings → Product cards, then check that the product's description contains text, not only images. The card uses the first 20 words without formatting; change the beginning of the product description to change the card copy. Compact Header search suggestions and Complementary products do not use this setting.
Purchase options, pickup, installments or recommendations are empty
These blocks are conditional. They stay empty or hidden when the selected variant or product does not supply the corresponding selling plan, pickup, payment-term or recommendation data.
The cart recommends the wrong product
Select an explicit Cart upsell product in the Cart section. When the selector is blank, Pastel Macaroon checks the first catalog product. If that product is unavailable or requires a selling plan, the upsell stays hidden.
How do I switch between the cart drawer and the full cart page?
Open Theme settings → Cart and change Cart behavior to Drawer or Cart page. Drawer is the default. You do not need to add a section to enable it. The drawer's View cart link always opens the full page; when already on that page, cart controls keep using it instead of opening another panel.
The Contact page omits the address or phone field
The physical address needs both Show store address enabled and address data available. Show phone field controls the customer phone input independently. The store email remains the contact detail and the customer Email address remains the required reply field.
Country, language, social or Follow on Shop controls are missing
The Footer omits empty or unavailable outputs. Localization needs multiple available choices; social icons need completed URL fields or store email; Follow on Shop needs both the theme toggle and an eligible returned control.
Can the same section be used more than once?
Yes. Addable sections use instance-specific settings and IDs. Keep pages focused and avoid unnecessary media-heavy duplicates.
Where should custom presentation code go?
Use the Custom Liquid section or block for small, maintainable presentation changes. Use a compatible app block for app-owned output. Retest either after updates because the theme cannot validate third-party or merchant-authored markup.
Which browsers should be used?
Pastel Macaroon targets current desktop and mobile browsers. Verify your own media, custom code and app blocks on the browser and device combinations used by your customers.

13 · Support

Pastel Macaroon support

Support covers reproducible defects in the current Pastel Macaroon release, clarification of documented settings, accessibility regressions caused by theme code and conflicts that can be reproduced in a clean, unmodified copy of the theme.

Service levels

  • New requests receive an initial response within two business days.
  • Critical defects that prevent browsing, adding a product to cart or reaching checkout are triaged immediately when received and prioritized for an emergency patch.
  • Confirmed ordinary defects are scheduled for the next appropriate patch release and tracked through validation, deployment and release notes.

Before opening a request

Prepare the store URL, Pastel Macaroon version, affected template, section or block, exact reproduction steps, expected and actual results, device/browser version, screenshots or video, and whether the issue remains in a clean unmodified copy.

Never send passwords, customer or payment data, API credentials, Theme Access passwords, private app tokens or unredacted admin screenshots. If diagnosis requires store access, support will request time-limited collaborator access with only the permissions needed to reproduce the theme defect.

Open the private support portal

Scope boundaries

Support does not include custom development, catalog entry, third-party app internals or defects introduced only by unsupported source modifications. We will help isolate whether a reproducible problem originates in Pastel Macaroon or in code and services outside the theme.

Private support intakeThe company support portal creates a private ticket and returns its ticket ID. Remove passwords, customer or payment data, credentials, private tokens and unrelated sensitive information before submitting the form or attachments.
