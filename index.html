Merchant guide · version 1.0.0

Build a polished store with Pastel Macaroon

This guide covers installation, theme-editor setup, product media, Shopify Markets, subscriptions, app blocks, safe updates and common problems.

Release candidate: version 1.0.0 is still completing Shopify Theme Store review preparation. The documentation describes the current committed theme.

01 · Setup

Getting started

Install the theme

  1. In Shopify admin, go to Online Store → Themes.
  2. Select Add theme → Upload zip file, then choose the Pastel Macaroon package.
  3. Open Customize on the unpublished copy. Keep the published theme available as a rollback until review is complete.
  4. Set the logo, typography and colors before configuring individual templates.
  5. Preview desktop and mobile, test product selection and cart, then publish when ready.
Installation does not copy demo catalog data. Products, collections, menus, policies, markets, files, selling plans and app configuration belong to the store. Select those resources in the theme editor after installation.

Recommended preparation

  • Create the main and footer navigation menus.
  • Add descriptive alt text and focal points to important images.
  • Configure shipping, payments, policies and customer accounts in Shopify admin.
  • Prepare at least one collection and product before configuring product-led home sections.

04 · Catalog presentation

Product media and swatches

Media

Add images, Shopify-hosted video, external YouTube/Vimeo video or 3D models in Products → select product → Media. The product gallery uses the selected variant's featured media first, renders thumbnails for multiple media items and opens images in an accessible dialog lightbox.

  • Write useful alt text for informative images. Decorative placeholders do not need merchant-written alt text.
  • Set focal points in Shopify for images that may be cropped.
  • Use compressed source files. The theme requests responsive Shopify CDN sizes but cannot repair a low-quality upload.
  • 3D/AR availability depends on a valid Shopify 3D model and customer device support.

Variant swatches

  1. Configure product option values and their swatch color or image in Shopify admin.
  2. In the product template, open the Variant picker block.
  3. Enable Show swatches. Values without swatch data remain readable text options.

Unavailable combinations are disabled or marked unavailable. Swatches never replace the accessible option name.

05 · International selling

Shopify Markets and localization

The footer uses Shopify's native localization form. Country/region and language controls appear only when the active store context offers more than one choice.

  1. Configure countries, regions, domains and currencies in Settings → Markets.
  2. Add and publish languages in Settings → Languages, then translate storefront resources and theme locale content.
  3. Preview each market from the theme editor or market selector and verify currency, policy, shipping and translation behavior.
What the theme does not configure Pastel Macaroon displays Shopify's localization data. It does not create markets, conversion rates, domains, duties, translations or payment methods.

06 · Subscriptions

Selling plans and purchase options

When a product has Shopify selling plans, Product and Featured product display one-time and plan choices, allocation prices, compare-at prices and unit prices. The selected selling-plan ID is submitted with the product form and shown again in the cart.

  1. Create selling plans using Shopify's subscription capabilities or a compatible subscription app.
  2. Assign plans to products and verify that each variant has the intended allocation.
  3. Keep the Purchase options block in the Product template.
  4. Test one-time, optional subscription and subscription-required products through cart and test checkout.

The theme does not create, bill, pause or manage subscriptions. Without selling-plan data, purchase-option controls stay hidden and ordinary purchases continue to work.

07 · Extensions

App blocks

Product and Featured product accept Shopify theme app blocks. Install the app first, then open the relevant section in the theme editor and select Add block → Apps.

  • Configure the app block through its own settings.
  • Place it in the intended order and test mobile, accelerated checkout and no-JavaScript fallbacks where relevant.
  • If the block disappears after uninstalling an app, remove the orphaned block from each affected template.

Core browsing and purchase behavior does not require an app. App output, subscriptions and review data remain the app provider's responsibility.

08 · Maintenance

Theme updates

  1. Duplicate the published theme and download a backup before updating.
  2. Review the new entry in the release notes and any migration instructions.
  3. Install the update as an unpublished theme. Do not overwrite the only working copy.
  4. Compare global settings, templates, app blocks and custom code. Reapply intentional code changes manually when Shopify cannot carry them forward.
  5. Test navigation, search, product variants, cart, Markets and checkout on desktop and mobile.
  6. Publish the verified copy and retain the previous theme for rollback.

Pastel Macaroon uses semantic `MAJOR.MINOR.PATCH` versions. Patch and minor releases preserve existing merchant configuration; a major release includes explicit migration instructions.

09 · Boundaries

Known limitations and prerequisites

  • The included locale is English. Add and publish translations for additional languages.
  • Complementary and related recommendations depend on Shopify recommendation data; an unconfigured response can be empty.
  • Pickup availability needs pickup-enabled locations and variant inventory.
  • Shop Pay Installments content depends on store, customer and product eligibility.
  • Follow on Shop appears only when Shopify returns an eligible follow control.
  • Predictive search enhances the header with JavaScript; the ordinary search form remains the fallback.
  • External YouTube/Vimeo playback depends on the provider, consent configuration and network availability.
  • Custom Liquid and app blocks can introduce markup, performance or accessibility issues outside the theme's control.

10 · Problem solving

Troubleshooting

A section is empty

Select the required product, collection, blog, image or video in the section settings. Some sections intentionally render a neutral placeholder or no wrapper when their resource is empty.

Filters are missing

Enable filtering in the Collection/Search section and configure storefront filters in Shopify Search & Discovery. Product type, vendor and tag fallbacks appear when native equivalents are unavailable.

Swatches show as text

Confirm that the option values have swatch color/image data in Shopify and that Show swatches is enabled in the Variant picker block.

Language or country selectors are missing

The controls are hidden when only one option is available. Publish another language or activate another market/country and preview the correct market context.

Selling plans are missing or unavailable

Verify selling-plan assignments for the selected variant. A subscription-required product without an allocation cannot be purchased until its plan data is corrected.

Changes do not appear

Confirm that you edited the correct template and theme copy. Save the editor, preview in a private window, and check whether an app or market-specific template is supplying different content.

11 · Frequently asked questions

FAQ

Does the theme install demo products or images?
No. Product, collection, menu, policy and media resources belong to the store and are selected after installation.
Can sections be used more than once?
Yes. Addable sections use instance-specific settings and IDs. Keep page length and performance in mind when creating many media-heavy sections.
Does the theme require Shopify Search & Discovery?
Core browsing works without an app. Native filter and recommendation configuration can improve results; empty recommendation data is handled safely.
Can customers purchase without JavaScript?
Core navigation, search, server-rendered variant selection, product submission, cart editing and checkout handoff have no-JavaScript fallbacks. Optional live enhancements are unavailable when scripts are disabled.
Where should custom code go?
Use a Custom Liquid section/block or an app block when possible. Duplicate the theme before editing source, and document changes because custom code might need manual migration during updates.
Which browsers are supported?
Use current evergreen desktop and mobile browsers. Test your own app blocks, consent tools and checkout setup on the devices important to your customers.

12 · Support

Support policy

Support covers reproducible defects in the current Pastel Macaroon release, clarification of documented settings, accessibility regressions caused by theme code and compatibility with supported Shopify storefront features.

Service levels

  • New requests receive an initial response within two business days.
  • Critical defects blocking storefront browsing, product purchase or checkout handoff are triaged immediately when received and prioritized for an emergency patch.
  • Confirmed ordinary defects are scheduled for the next appropriate patch release and tracked through validation, deployment and release notes.

Before opening a request

Prepare the store URL, theme version, affected template, exact reproduction steps, expected and actual results, device/browser version, screenshots or video, and whether the issue remains in a clean unmodified copy.

Scope boundaries

Support does not include custom development, catalog entry, third-party app internals, Shopify admin/account configuration, subscription billing rules or issues reproducible only after unsupported source modifications. We will still help identify whether the defect belongs to the theme, Shopify platform or an app provider.

Support intake status A public request form and its operational escalation workflow are a separate pre-release deliverable. Until that endpoint is published in Theme info, this page states the policy but does not claim that intake is active.
